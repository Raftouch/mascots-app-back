# 🐾 PawPals Backend

Backend API for the PawPals application, built with **Node.js** and **Express.js**.  
It handles **authentication, authorization**, and data management for collaborators and mascots (dogs).

---

## 🚀 Features

- User authentication (registration, login)
- Authorization (protected routes)
- Password hashing with bcrypt
- CRUD for collaborators
- CRUD for mascots
- Search mascots by name and age
- MongoDB database integration
- RESTful API architecture

---

## 🛠️ Tech Stack

- Node.js
- Express.js
- MongoDB + Mongoose
- bcrypt
- express-validator
- express-session / passport
