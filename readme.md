# 🐾 PawPals Backend

Backend API for the PawPals application, built with **Node.js** and **Express.js**.  
It handles data management for collaborators and mascots (dogs), as well as user registration.

---

## 🚀 Features

- User registration with password hashing (bcrypt)
- Full CRUD for collaborators
- Full CRUD for mascots (dogs)
- Search mascots by name and age
- MongoDB database integration
- RESTful API architecture

---

## 🛠️ Tech Stack

- Node.js
- Express.js
- MongoDB + Mongoose
- bcrypt
- express-validator
- express-session / passport
